본 앱 TickLab (이하 "본 앱") 의 다운로드 및 사용은 Apple Inc. 가 정한 표준 EULA (End User License Agreement) 를 따릅니다. App Store 표준 EULA 전문은 Apple 표준 EULA 에서 확인하실 수 있습니다. 본 앱은 사용자 생성 콘텐츠(커뮤니티)를 포함하므로 17세 이상이 이용할 수 있습니다.

1. 구독

TickLab Pro 는 월간 / 연간 자동 갱신 구독으로 제공됩니다. 가격은 App Store에 표시된 지역별 금액을 따르며, 결제는 Apple App Store가 처리하고 사용자의 Apple ID에 등록된 결제 수단으로 청구됩니다. 구독은 갱신 기간 종료 24시간 이내에 취소하지 않으면 자동으로 갱신됩니다.

구독 관리·취소는 iPhone 설정 → [Apple ID] → 구독 또는 앱 내 설정 → 계정 카드에서 가능합니다.

2. 환불

환불은 Apple App Store 의 환불 정책을 따릅니다. reportaproblem.apple.com 에서 환불 요청을 제출하실 수 있습니다.

3. 커뮤니티 및 사용자 생성 콘텐츠

본 앱의 커뮤니티는 익명 사진/글 피드입니다. 게시 전 별도의 커뮤니티 약관에 동의해야 하며, 게시 시 다음에 동의하는 것으로 간주됩니다.

  • 무관용(Zero-tolerance): 욕설·선정적·혐오·불법·괴롭힘 콘텐츠를 일절 게시할 수 없습니다. 위반 시 즉시 삭제·차단됩니다.
  • 타인 권리 존중: 타인의 사진·개인정보를 동의 없이 게시할 수 없으며, 본인이 권리를 가진 콘텐츠만 게시해야 합니다.
  • 신고·차단: 부적절한 게시물·사용자를 신고·차단할 수 있으며, 신고된 콘텐츠는 24시간 내 조치됩니다. 온디바이스 콘텐츠 필터가 함께 적용됩니다.
  • 콘텐츠 라이선스: 게시한 콘텐츠의 소유권은 사용자에게 있습니다. 사용자는 본 앱이 해당 콘텐츠를 커뮤니티 내에서 표시·배포하는 데 필요한 비독점적 라이선스를 부여합니다. 게시물은 본인이 직접 삭제할 수 있습니다.
  • 게시 제한: 게시는 하루 1건으로 제한됩니다.

4. 측정 데이터의 한계

본 앱의 측정 결과는 참고용입니다. 마이크 기반 측정은 환경 (소음·자세·동력) 에 따라 오차가 발생할 수 있으며, 정확한 정비 판단은 전문 워치메이커 또는 Witschi 같은 산업용 측정기 결과를 기준으로 하시기 바랍니다.

5. 책임 한계

본 앱의 측정·진단 결과로 인해 발생한 시계 손상·정비 비용·기타 손실에 대해 개발자는 책임지지 않습니다. 사용자는 본 앱의 결과를 참고 정보로만 활용해야 합니다.

6. 지적재산권

본 앱의 코드·디자인·로고·콘텐츠는 TickLab 의 지적재산이며, 무단 복제·배포·역공학을 금지합니다. 사용자가 본 앱에 입력한 데이터 (시계 정보·사진·일기) 의 소유권은 사용자에게 있습니다.

7. 약관 변경

본 약관은 필요 시 업데이트될 수 있으며, 변경 사항은 본 페이지를 통해 공지됩니다. 변경 후 본 앱을 계속 사용하는 것은 변경된 약관에 동의하는 것으로 간주됩니다.
