## 설명 (Description · 최대 4000자)
```
TickLab — 내 시계와 함께하는 모든 순간을 기록·관리·분석·공유하는 시계 라이프 플랫폼

정확도 측정에서 출발했지만, TickLab은 컬렉터의 하루 전체를 담습니다.

◆ 정확도 측정 · AI 진단
별도 장비 없이 iPhone 마이크만으로 기계식 시계의 일오차(rate)·비트 에러·진폭을 측정합니다. 신뢰도 등급(A~F)과 AI 해석으로 결과를 쉽게 이해하고, 폰 시계 자동 보정으로 정밀도를 높였습니다. 깨끗한 신호에서 같은 자세 단일 측정은 약 ±2초/일, 여러 번 평균 시 ±1초/일까지 좁힐 수 있습니다.

◆ 컬렉션 관리
시계마다 스펙·사진·시리얼·구매가와 재무를 정리하고, 오버홀·정비 시기를 자동으로 알려드립니다.

◆ 생활 기록
착용 기록·일기·추억 하이라이트·이벤트 태그로 시계와 함께한 순간을 남깁니다.

◆ 분석
주간·월간·연간 트렌드, 월별 착용 heatmap, 연말 Wrapped, 글로벌 브랜드 리그로 내 시계 생활을 한눈에 봅니다.

◆ 익명 커뮤니티
닉네임 없는 사진 피드에서 좋아요·댓글·팔로우하고 뱃지를 모으세요. 신고·차단·콘텐츠 필터로 안전하게 운영됩니다. (17세 이상)

— 개인정보 —
측정 데이터·시리얼·구매가는 기기 안에만 저장되며 외부로 전송되지 않습니다. 커뮤니티 사진은 위치정보(EXIF)를 제거한 뒤, 사용자가 직접 게시 버튼을 눌렀을 때만 업로드됩니다.

— TickLab Pro —
무료로 시작하고, 월간 또는 연간 구독으로 모든 기능을 사용하세요.
• TickLab Pro 월간 — 1개월 자동 갱신
• TickLab Pro 연간 — 1년 자동 갱신
가격은 App Store에 표시된 지역별 금액을 따릅니다. 결제는 구매 확인 시 Apple ID로 청구되며, 현재 구독 기간 종료 24시간 이내에 자동 갱신을 끄지 않으면 자동으로 갱신됩니다. 구독 관리·해지는 기기 설정 → Apple ID → 구독에서 할 수 있습니다.
```
