개인정보처리방침

최종 업데이트: 2026년 6월 2일

TickLab (이하 "본 앱") 은 사용자의 개인정보 보호를 매우 중요하게 생각합니다. 본 앱은 기본적으로 모든 데이터를 사용자의 기기 내부에만 저장합니다. 외부로 전송되는 항목은 ⓐ사용자가 직접 게시 버튼을 눌러 공유한 커뮤니티 콘텐츠, ⓑ사용자가 보낸 피드백, ⓒ사용자가 설정에서 켠 선택 기능에 한정되며, 아래에 명시합니다.

1. 기기 내부에만 저장되는 정보

  • 마이크 입력: 측정 중 실시간으로 시계 박동을 분석하는 데만 사용됩니다. 오디오는 즉시 폐기되며 녹음·저장·전송되지 않습니다.
  • 측정 데이터(일오차·진폭·비트에러)·시리얼 번호·구매가: 기기 내부 로컬 데이터베이스(SwiftData)에만 저장되며 어떤 경우에도 외부로 전송되지 않습니다.
  • 일기·정비 기록·착용 기록·시계 사진: 모두 기기 내부에만 저장됩니다. 사진은 저장 시 EXIF 위치 정보가 제거됩니다.
  • 자기장 센서: 시계 자성화 위험 확인용. 측정값은 기기 내부에서만 처리됩니다.

2. 사용자 동의 하에 외부로 전송되는 정보

다음 항목은 사용자의 명시적 행동(게시·전송·옵트인)이 있을 때만 백엔드 서버(Supabase)로 전송됩니다.

  • 커뮤니티 사진/글 게시(사용자 주도): 사용자가 '게시' 버튼을 눌러 공유한 사진 1장 또는 글이 공개 피드에 게시됩니다. 사진은 EXIF 위치 정보가 제거된 뒤 업로드되며, 함께 전송되는 정보는 표시명·선택한 브랜드/장착 뱃지·한 줄 캡션뿐입니다. 측정 데이터·시리얼·구매가는 전송되지 않습니다. 커뮤니티는 익명으로 표시되지만, 검열·차단·소유권 확인을 위해 내부 안정 식별자(익명 인증)가 사용됩니다. 게시는 하루 1건으로 제한됩니다.
  • 좋아요·댓글·팔로우·신고·차단: 커뮤니티 상호작용 시 해당 동작과 익명 식별자가 서버에 기록됩니다. 부적절한 콘텐츠는 신고·차단할 수 있으며 24시간 내 조치됩니다.
  • 피드백(사용자 전송): 설정 → 피드백 보내기로 보낸 유형·메시지·앱 버전이 운영자에게 전달됩니다.
  • 브랜드 리그(선택 · 기본 꺼짐): 설정에서 직접 켠 경우에만, 등록한 시계 브랜드명과 착용 빈도가 익명으로 글로벌 랭킹 서버에 전송됩니다. 개인 식별 정보·시리얼·사진은 전송되지 않습니다.

3. 제3자 서비스

  • Supabase: 커뮤니티·피드백·브랜드 리그 데이터의 백엔드 호스팅에 사용됩니다(위 2항 범위 내).
  • Apple App Store / StoreKit: 구독 결제 처리. 본 앱은 결제 카드·청구 정보에 직접 접근하지 않습니다.
  • YouTube: 추천 영상 피드는 운영자가 큐레이션한 채널의 공개 RSS를 불러옵니다. 시청은 YouTube에서 이뤄지며 별도 개인정보를 전송하지 않습니다.
  • 원자시계 시각 동기화(NTP): 측정 정확도를 위한 기기 시계 보정에만 표준 시각을 조회하며, 개인정보를 전송하지 않습니다.

4. 결제 정보

TickLab Pro 구독(월간 / 연간)의 결제는 Apple App Store가 모두 처리합니다. 본 앱은 사용자의 결제 카드 정보·청구 주소·Apple ID에 직접 접근하지 않습니다. 자세한 내용은 Apple 개인정보처리방침을 참조하세요.

5. AI 진단

측정 결과 AI 진단·시계 설명은 Apple Intelligence (FoundationModels)를 사용해 기기 내부에서 처리됩니다. 측정 데이터는 Apple 또는 외부 서버로 전송되지 않습니다. Apple Intelligence 미지원 디바이스에서는 규칙 기반 fallback이 동작합니다.

6. 데이터 보관 및 삭제

기기 내 데이터는 SwiftData에 저장됩니다. 앱을 삭제하면 함께 영구 삭제됩니다. 설정·시계 디테일에서 개별 시계·측정·일기·서비스 기록을 언제든 삭제할 수 있으며, 측정 기록은 CSV로 내보낼 수 있습니다. 커뮤니티 게시물은 본인이 직접 삭제할 수 있고, 신고·운영자 조치로도 숨김·삭제될 수 있습니다.

7. 권한

  • 마이크 — 시계 박동 측정
  • 카메라 — 시계 사진 촬영
  • 사진 라이브러리 — 기존 사진 선택 / 공유 카드 저장 / 커뮤니티 게시
  • 알림 — 일기·정비·랜덤 시계 추천·커뮤니티 활동 알림
  • Face ID — 앱 잠금 (선택)

8. 연령 및 아동 보호

본 앱은 사용자 생성 콘텐츠(커뮤니티)를 포함하므로 17세 이상을 대상으로 합니다. 13세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 커뮤니티는 무관용(zero-tolerance) 정책과 신고·차단·온디바이스 콘텐츠 필터로 운영됩니다.

9. 방침 변경
