## 핵심 교차 발견 (여러 직군이 동시 지목)

1. **만들어 놓고 안 켠 코드 (최고 ROI, 신규 X)** — RotationNudgeService 미배선·ReferralService 보상 없음·DSP clock-drift 보정 미적용·Hard Rule #9 amplitude 게이팅 死코드.
2. **"내 시계 정상인가?" = 진짜 해자** — 캘리버별 글로벌 rate 분포(측정·헤비·전략 3직군 + 이전 커뮤니티 토론 공통). 단 Hard Rule #8(측정 외부전송) 개정 + opt-in 필요.
3. **백업/복원 부재** — 단방향 export만, 기기변경 시 데이터 소실. 로컬 import 복원은 #8 무충돌.
4. **접근성 법적 리스크** — accent gold 텍스트 대비 2.25:1(WCAG 미달), 측정 VoiceOver 합성라벨 부족.
5. **커뮤니티 고립** — `brand:nil` 익명 사진만 = 인스타 클론 위험. 측정/시계 맥락(ShareCard) 통합해야 차별화.
